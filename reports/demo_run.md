# Recommendation Ranking Demo

Generated by `python -m src.run_demo` using the actual saved XGBoost artifact and the same `/rank` request handler used by FastAPI. The request contains five deterministic held-out candidates for MovieLens user 842, with precomputed historical features; it does not demonstrate candidate generation inside the API.

- Request: `reports/demo_request.json`
- Response: `reports/demo_response.json`
- Candidates submitted: **5**; results returned (`top_k=3`): **3**.

The returned scores are ranking scores, not probabilities. The endpoint checks feature names and values, scores candidates, sorts descending, and applies `top_k`. To demonstrate the HTTP server interactively, run `uvicorn app:app --reload` and use `/docs` with the saved request.
